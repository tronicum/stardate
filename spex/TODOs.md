## Licensing gaps found while answering issue #2 (2026-08)

- **`tileset.json` carries no attribution at all.** The mesh path writes an `attribution` block into `mesh.json`; the point-cloud path (`brick-part` → `spex-tiler`) writes none — so a tileset built from LDraw geometry is LDraw-derived 3D data shipped with no credit. LDraw's own rule is that 2D renders are *not* derivative works but 3D→3D conversions are, which is exactly what a tileset is. Fix: `spex-tiler` gains an optional attribution block and the brick verbs fill it.
- **The attribution string that does exist is stale.** `"LDraw Parts Library (ldraw.org), CCAL 2.0"` — but the current Contributor Agreement (rev. 2024-06-06) releases under **CC BY 4.0** (or CC0), and `CAreadme.txt` says *"'CCAL version 2.0' should be read to mean CC BY 2.0"* with anything modified on or after 2023-03-05 under CC BY 4.0. It should name the per-file licence, carry the licence URL, and state that the work was modified — converting to a bundle plainly is a modification.
- **`!LICENSE` is not parsed at all.** The header spec permits `0 !LICENSE Not redistributable : see NonCAreadme.txt`, and `spex-ldraw` ignores the line entirely, so such a part is converted and published silently. This has to land inside any batch-render mode rather than beside it: a batch job that skips a non-redistributable part *and names it* is strictly better than a separate lint nobody runs.
- **spex is CC BY-NC-SA 4.0, which is not a software licence.** Creative Commons say so themselves. `export-static` ships the viewer bundle, so anyone embedding it is redistributing spex under NC + SA. That is workable for a non-commercial archive and will keep generating the same conversation; worth deciding whether to dual-license or to grant a written exception for scientific/archival reuse. **Stefan's call, not the implementing session's.**
